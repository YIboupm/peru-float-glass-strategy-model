# 跨国估计：建筑业 → 平板玻璃需求的弹性与滞后

秘鲁自己只有约6到9个可用年度数据点，估不出可靠的弹性。这里借用欧洲四国（德国、西班牙、法国、意大利）1990–2025年的长周期数据来估计。

## 数据

全部来自欧盟统计局短期统计（年度、2021=100的生产量指数，日历调整），原始数值和查询地址见 `eurostat_indices.json`。

- 玻璃需求代理：**C2312 平板玻璃深加工**（钢化、夹层、中空玻璃）。成品体积大、易碎，主要供应本国市场，比浮法原片产量更贴近本国建筑用玻璃。
- 对照组：**C2311 平板玻璃制造**（浮法原片）。原片大量出口，用来说明"产量不等于需求"。
- 建筑活动：**F41 房屋建筑**（德、西、法），以及 **F 建筑业整体**（四国，含修路架桥等几乎不用玻璃的工程）。

## 方法

- 只用年增长率（对数差分）回归。指数的水平值都有趋势，直接回归会得到虚假相关。
- 斜率 = 周期弹性；截距 = 各国自身的长期趋势（例如节能法规让每扇窗用玻璃更多）。只有斜率有可能迁移到秘鲁。
- 面板回归加国家截距，HC1稳健标准误；同时报告剔除2020–2021年疫情的结果。

## 运行

```text
python analysis/cross_country_elasticity/estimate.py
```

输出 `results.md` 和 `results.json`。只用 numpy 和 scipy，不联网。

## 已知局限

- C2312 也包含汽车安全玻璃，不全是建筑用量。
- 年度数据只能分辨"当年或滞后一年"，更细的滞后结构需要季度数据。
- 成熟市场的翻新和换窗比例高，可能压低弹性；秘鲁新建和自建房比例高，真实弹性可能更高。
- 中国未纳入：国家统计局数据库从境外访问被拒，年鉴表格只有图片且每本只列4年，转载网站的序列在2017到2018年有明显口径断点。

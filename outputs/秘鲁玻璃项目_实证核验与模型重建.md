# 秘鲁玻璃项目：公开资料核验与可复算模型

研究截止：2026年10月26日。五年规划窗口：2027—2031年。

本次实际读取了公司公告、企业官网、UN Comtrade公开接口、世界银行WITS及秘鲁央行数据；保存了18份贸易接口响应，做了6组需求回归和28组优化/压力测试。本文的事实、推算与情景假设分别标识。没有把未获得的物流报价、工厂成本或客户转化参数当作已验证数据。

主要发现：工厂规模与秘鲁既有浮法类原片进口量接近；需要验证的是进口替代速度、可保留的单吨贡献和出口补量。现有公开年度数据不能识别稳定的正向建筑业需求弹性。模型中价格和工厂变动成本的利润敏感性超过运费。以单吨毛利给市场排出唯一进入顺序，缺少依据。

## 1. 核实了哪些事实

### 工厂规模与渠道基础

特福官网披露设计年产能198,090吨，2026年9月10日点火；科达官网新闻及10月报道显示工厂于10月7日正式投产。年设计产能不能直接与600×365=219,000吨等同，差异可能涉及有效生产天数、设计成品口径等，公开材料不足以分解。模型暂以198,090吨作工作上限，不再无依据重复扣减良品率。

### 关税处理

SUNAT公布的2022税则中，本次涉及的主要7005子目一般从价税列为0；不能预设进口原片在秘鲁受到较高关税保护。[SUNAT税则，第207页](https://www.sunat.gob.pe/legislacion/procedim/normasadua/gja-04/ctrlCambios/anexos/Arancel_2022.pdf)。这是对公布税则的核对，具体出货仍须核对当期十位税号及附加措施。

符合原产地规定的秘鲁货物，向安第斯共同体其他成员和智利出口有零关税制度基础。因此模型用0作为条件基准，未把增值税抵扣项当作永久成本。来源：[玻利维亚海关CAN说明](https://portal.aduana.gob.bo/aduana7/content/comunidad-andina-can)、[秘鲁—智利协定说明](https://www.acuerdoscomerciales.gob.pe/en_vigencia/chile/inicio.html)。

哥伦比亚对中国无色浮法原片的该轮反倾销调查，于2025年5月终止且未征最终反倾销税；不能把保护性附加税作为当然的价格优势。[哥伦比亚贸易部案件记录](https://www.mincit.gov.co/mincomercioexterior/defensa-comercial/dumping/investigaciones-antidumping-concluidas/vidrio-flotado-o-vidrio-incoloro-placas-o-en-hojas)。

建筑业采用秘鲁央行PM04997AA：以2007年价格计的建筑业增加值。贸易量采用2012—2024年HS7005进口净重减出口净重。2014、2016、2017、2018年进口净重缺失，直接剔除，没有填零或以进口金额填补；2025年该次接口查询返回空结果，未将其解释为零进口。

若按最高R²选择，原方案会选出负弹性。它可能反映进口库存周期、供应变化、产品组合和建筑项目结构，而不能证明建筑活动使玻璃使用量下降。

扩展窗口检验中，水平模型一年滞后在2021—2024年四个检验点的平均绝对百分比误差约4.2%，优于“沿用上一年净进口量”的14.7%。这一短窗口表现值得继续研究，但不足以把负系数用于五年因果外推。增长率模型仅有两个留出点；部分输入本身为数据库估算。检验使用已实现建筑数据，不是实时预测回测。

因此，本轮不把任何回归系数当作已识别的需求弹性。实施模型用0%、3%、6%年需求增长作压力情景；3%是分析假设，不冒充央行玻璃需求预测。需要逐月重量、库存与建筑完工/装修指标后，才能进一步估计分布滞后、修复数据断点并扩大样本外检验。

## 3. 重建的可运行模型

不采用主观“运费占40%、需求占30%”一类加权评分。直接让价格影响市场份额、单位贡献和渠道投入，再检验参数变化造成的结果变化。

基期市场池为D_i0，规格适配为phi_i，情景需求为：

$$A_{i,t}=D_{i,2024}(1+g)^{t-2024}\phi_i.$$

先用历史CIF均值加假设的进口后内陆配送费用，构成暂定交付参考价B_i。折扣d是决策变量：

$$P_i=B_i(1-d_i),\qquad s_{i,j}^{\infty}=s_i^{max}q_j\frac{1}{1+\exp[-\beta(d_i-d^*)]}.$$

q_j表示渠道覆盖能力。原式把“供应成本较低”等同于“客户能买得更便宜”，会忽视定价选择；重建后，降价直接压低每吨贡献，同时提高潜在成交份额。

设a为进入后的整年数，初始份额为s_i0，采用一年内平均份额：

$$\bar s_{i,j,a}=s_{i,j}^{\infty}+(s_{i,0}-s_{i,j}^{\infty})e^{-\lambda_j a}\frac{1-e^{-\lambda_j}}{\lambda_j}.$$

新市场s_i0=0，首个完整销售年仍有销量。已有市场可保留初始客户基础；如果新报价吸引力下降，已有份额也允许逐步流失。原模型在进入当年令R=0，会人为强制全年零销售。

每个市场预计算“进入年、主渠道、价格折扣”的策略选项k，计算对应潜在销量上限Vbar_ikt和单位贡献m_ik。二元变量z_ik选择一个选项，连续变量x_ikt分配实际销量：

$$\max \sum_{i,k,t}\frac{m_{ik}x_{ikt}-F_{ik,t}z_{ik}}{(1+r)^{t-2026}}-\sum_{i,k}\frac{E_{ik}z_{ik}}{(1+r)^{e_{ik}-2027}},$$

$$\sum_kz_{ik}\leq1,\quad0\leq x_{ikt}\leq\bar V_{ikt}z_{ik},\quad\sum_{i,k}x_{ikt}\leq K_t.$$

进入投入在入场年初支付，经常收入和费用按年末折现。费用统一由卖方交付口径计入，不能在到岸价、净实收价和贡献计算中重复扣除物流。

求解使用SciPy/HiGHS混合整数优化。基准价格折扣0%—40%、步长2个百分点，并用1个百分点网格复核。渠道和折扣规则自进入后保持至2031年；没有模拟中途切换。每个国家一个主渠道是用于筛查的简化，实际部署应下沉到客户/地区/产品，允许直营和经销并行。

模型的五年折现渠道贡献约3,185万美元。它扣除了销售变动成本、渠道固定成本和进入投入，但没有扣工厂固定费用、工厂投资、所得税、营运资金或融资费用。不得称为项目净现值、净利润或投资回报。

将折扣网格从2个百分点细化到1个百分点，折现渠道贡献只上升约0.23%，但第五年销量从15.91万吨变为16.96万吨。这显示利润最优附近可能存在销量不同、收益接近的方案，不应把某个精确销量当成可靠预测。

额外要求第五年销量达到设计产能90%，可行解达到约17.91万吨、消化率90.4%，折现渠道贡献约3,157万美元，仅比基准少约28.6万美元、0.9%。渠道组合保持不变，主要通过改变折扣实现。是否值得采用该方案，要加上连续生产的成本、库存与现金约束后判断。

## 6. 重新计算参数重要性

下表每次改变一个参数并重新优化，基准为3,185万美元折现渠道贡献。它衡量条件敏感性，不是参数真实概率、统计重要性或可直接使用的加权系数。

|---|---:|---:|
| 客户交付参考价格 | -89.2% | +127.7% |
| 工厂每吨变动成本 | +74.8% | -60.1% |
| 市场需求池 | -22.0% | +22.0% |
| 理论份额上限 | -19.9% | +19.9% |
| 我方运费 | +14.9% | -13.2% |
| 换供应商折扣门槛 | +10.8% | -10.2% |
| 渠道爬坡lambda | -7.2% | +5.4% |
| 价格曲线beta | -4.9% | +4.6% |

门槛的±20%指8%变为6.4%/9.6%，不是加减20个百分点。价格冲击是全部市场参考价同步变化，是广泛价格战压力测试，不是仅对中国货降价的精确预测。运费只改变我方运费，不联动竞争者价格。

固定原有渠道投入、进入时间和相对折扣规则，再让参考价下降20%，折现渠道贡献仅约7万美元；允许事先重新选择渠道和报价的最优值约345万美元。两者之差揭示了不可随时撤回的渠道投入风险。这里只固定相对折扣，不是假定绝对美元报价完全不变；销量仍可缩减，不生产最低量的成本尚未计入。

联合不利情景：需求零增长、换商门槛12%、变动成本264美元/吨、参考价格下降15%、运费上升20%，模型只剩极少正贡献销售。联合有利情景：需求增长5%、门槛6%、变动成本216美元/吨、运费下降10%，第五年达到全部产能。没有给这些情景赋发生概率，也没有用任意蒙特卡洛分布制造置信区间。

当前优先补数顺序，应是同规格成交价及竞品反应、真实分规格变动成本、可转化客户订单量、逐线路物流报价。运费仍重要，但不能先验认定它一定排第一。

| 60% | 11.16 | 6.66 |
| 70% | 13.02 | 4.80 |

这张表使用设计能力，不是2027年85%的情景爬坡能力，目的在于检验接近成熟运行时的订单要求。即使不相信logistic曲线，也能用它检查国内订单与出口承诺是否足够。

若满产时七成内销，则年内销目标13.866万吨，约占上述2027年可服务池的74.5%，出口约5.943万吨。“七成内销”指产量去向占比，不是国内市场份额，两者不可混淆。

## 8. 对策略的可执行含义

秘鲁是最有证据支持的规模核心市场：工厂在本国、已有渠道，且进口替代池与产能同一数量级。应先核验既有客户按规格的月采购量、向本地产切换的保留率及交付报价，判断国内能否形成9万—13万吨量级的有效年订单。

出口宜作为早期并行验证任务。按国内可服务池50%—70%的份额假设，要达到设计能力90%，需约4.8万—8.5万吨出口补量。用几个有付款条件、规格和最低采购量的经销合同验证这个目标，比先按地图距离给国家排队更有决策价值。

模型偏好秘鲁直营、其他已量化市场经销，但这只能列为报价核验对象。一个国家可同时有工程直销、加工厂直供和区域经销，不应将“每国一种渠道”的简化当成组织设计限制。仓库决策还要计入库存资金、账期、坏账与共享服务，单一盈亏平衡吨数仅适用于两渠道销量与售价相同的情况。

对哥伦比亚，先补齐无色原片重量及本地竞争者客户价格；其缺失品类进口额本身很大，不能以当前模型的小销量排除。对智利，先取得北部目的地报价和客户需求，不能把全国进口量都当作北部可服务市场。

正式销售与生产计划还需增加：按规格的产能和切换损失、窑炉最低稳定产量、库存平衡与库容、生产固定费用、营运资金和客户回款。这些数据不足时，本次模型可评估订单吸收和渠道贡献，尚不能验证工厂现金盈亏或投资可行性。

库存平衡应写为I_t=I_(t-1)+产量-销量-损失。若库存变化定义为期末减期初，消费量=进口+产量-出口-库存增加；上一轮回复写成加库存增加，方向错误。上一轮建议的“NPV除以启动投入”也不能保证产能受限时最优，因此本次改为联合优化。
